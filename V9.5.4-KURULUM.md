## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

  Stop-Process -Force

```

## Veriyi güvenli biçimde alma

İlk çalıştırmada 15 Ağustos 2026'dan bugüne kadar en fazla 250 tamamlanmış maç işlenir. Her maç bir API isteğidir; daha önce eksiksiz kaydedilmiş maçlar tekrar çağrılmaz.

```powershell
$env:CONFIRM_MATCH_STATS_IMPORT = "YES"
$env:MATCH_STATS_FROM = "2026-08-15"
$env:MATCH_STATS_TO = (Get-Date).ToString("yyyy-MM-dd")
$env:MATCH_STATS_MATCH_LIMIT = "250"
$env:API_FOOTBALL_MIN_INTERVAL_MS = "1200"

pnpm run statistics:import-v9
pnpm run statistics:coverage-v9

Remove-Item Env:CONFIRM_MATCH_STATS_IMPORT
Remove-Item Env:MATCH_STATS_FROM
Remove-Item Env:MATCH_STATS_TO
Remove-Item Env:MATCH_STATS_MATCH_LIMIT
Remove-Item Env:API_FOOTBALL_MIN_INTERVAL_MS
```

Kalan eksik maçlar varsa aynı komut ertesi çalıştırmada kaldığı yerden devam eder. API 429 veya günlük kota hatasında aktarım yeni maçlara istek göndermeden güvenli biçimde durur.
