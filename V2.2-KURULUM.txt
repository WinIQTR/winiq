BET PROJECT V2.2 — AI MAÇ AÇIKLAMA MOTORU

Bu paket V2.1 Portföy ve Risk Motoru kurulumu üzerine uygulanır.

1. Çalışan geliştirme sunucusunu terminalde Ctrl+C ile durdurun.

2. ZIP dosyasını açın ve içindeki dosyaları Bet Project ana klasörüne
   kopyalayın. Sorulduğunda mevcut dosyaların üzerine yazılmasına izin verin.
   src, scripts ve package.json yolları korunmalıdır.

3. Proje klasöründe şu kontrolleri çalıştırın:

   npm run test:explanation-v2
   npm run test:portfolio-v2
   npm run test:value-v2
   npx tsc --noEmit

4. Uygulamayı yeniden başlatın:

   npm run dev

5. /value-bets sayfasında Ana Öneriler tablosunun altındaki
   "AI Maç Açıklamaları" bölümünü açın. Her maç satırına tıklayarak
   sayısal açıklamayı görebilirsiniz.

V2.2 AÇIKLAMA İÇERİĞİ

- Model olasılığı ile piyasa olasılığı arasındaki fark
- Adil oran ile bulunan en iyi oran arasındaki oran primi
- Bir birim miktar başına beklenen kâr
- Kaç bahis şirketinin fiyatının karşılaştırıldığı
- Günlük %6 sınır içindeki portföy miktarı
- Elit / Çok Güçlü / Güçlü / Eşiği Geçen değer sınıfı
- Güveni destekleyen sayısal sinyaller

ÖNEMLİ

Açıklamalar dış bir yapay zekâ servisine gönderilmez. Yayımlanmış model ve
bahis şirketi verilerinden deterministik olarak üretilir; bu nedenle tabloda
görünen sayılarla her zaman tutarlıdır.

Bu sürüm ayrıca "8 prices / 9 prices" metninin Türkçe görünmesini düzeltir.
Yeni bağımlılık, veritabanı göçü veya yeni oran aktarımı gerekmez.
