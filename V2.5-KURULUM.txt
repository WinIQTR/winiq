BET PROJECT V2.5 - LEAGUE PROFILE ENGINE TAM KUMULATIF PAKET

Bu paket V2.4.2 uzerine kurulur ve V2.5 icin gereken tum dosyalari birlikte icerir.

EKLENENLER
- Her lig icin bagimsiz Value Bet performans profili
- Isabet orani, ROI, kalibrasyon farki, Brier ve guvenilirlik puani
- 40 sonuc: lig/sezon kalibrasyon profiline hazir
- 100 sonuc: guvenilir lig orneklemi
- 500 sonuc: genis orneklem
- 1000 sonuc: maksimum orneklem guveni
- Guven puani: %50 tarihsel isabet, %20 kalibrasyon, %15 orneklem, %15 Brier
- Ayni mac tekrarlarini lig profiline yalniz bir kez dahil etme
- Otomatik lig agirligi ve production degisikligini engelleyen kilit

KURULUM
1. Calisan pnpm dev islemini Ctrl+C ile durdurun.
2. ZIP dosyasini ayri bir klasore acin.
3. src, scripts ve package.json dosyalarini birlikte proje ana klasorune kopyalayin.
4. Soruldugunda Replace the files in the destination secenegini kullanin.

KOMUTLARI TEK TEK CALISTIRIN

pnpm run test:league-profile-v2
pnpm run test:learning-v2
pnpm run test:accuracy-v2
pnpm run test:portfolio-v2
pnpm run test:explanation-v2
pnpm exec tsc --noEmit

Hepsi basariliysa:

pnpm dev

Tarayici:
http://localhost:3000/value-bets
