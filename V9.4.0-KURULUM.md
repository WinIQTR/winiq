# Bet Project V9.4.0

Bu paket V9.3.9'un tüm dosyalarını ve birleşik 27 pazar performans merkezini içerir.

## Yenilikler

- `/match-result-performance` artık tek bir maç sonucu sayfası yerine 27 bahis türünü kapsayan performans merkezidir.
- Üst seçim kutusundan 01–27 arasındaki istenen bahis türü seçilir.
- Başarı halkası, KPI kartları, puan seviyesi, olasılık dilimleri ve maç listesi seçilen pazara göre anında yenilenir.
- Her maçta seçilen pazarın en yüksek puanlı seçimi değerlendirilir.
- Kazandı, kaybetti, iade ve veri bekleniyor sonuçları ayrı gösterilir.
- Model olasılığı, puan, adil oran, kesin skor ve sonuç aynı satırda bulunur.
- Arama; sonuç, puan seviyesi ve olasılık filtreleri eklendi.
- Maç Sonucu pazarında `%30+` 1X2 favori kuralı korunur.
- Yalnızca maçtan önce arşivlenmiş model verileri kullanılır.
- Skordan doğrulanamayan ilk yarı, kart, korner, oyuncu ve olay pazarlarında sonuç uydurulmaz; `VERİ BEKLENİYOR` gösterilir.
- Sayfa önbelleğe alınmaz ve her açılışta güncel arşivi yeniden okur.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.4.0*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.4.0 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:match-result-performance-v9
pnpm run test:bet-market-catalog-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Bu sürüm Prisma migration içermez ve model ağırlıklarını değiştirmez.
