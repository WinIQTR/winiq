# Bet Project V9.3.3 — Kompakt Tahmin Geçmişi ve 27 Pazar Sonuçları

Bu paket V9.3.2 üzerine kurulabilen kümülatif güncellemedir. Cloud V9 tabanı,
%20 ML / %80 Poisson kilidi, arşiv akışı ve mevcut veritabanı şeması korunur.

## Yenilikler

- Tahmin Geçmişi maç bazında tek satırlık kompakt açılır listeye dönüştürüldü.
- Üst satırda lig, tarih, takımlar, kesin skor, tahmin adedi ve Kazandı/Kaybetti/İade özeti gösterilir.
- Olasılık/güven seçimi, bahis türü ve aralık filtreleri tek araç çubuğunda toplandı.
- Tam sonuç arşivine doğrudan `27 Pazar Sonuçları` bağlantısı eklendi.
- Sonuçlanan maçlarda 27 bahis grubunun hesaplanabilen tüm seçenekleri Kazandı, Kaybetti veya İade olarak işaretlenir.
- Önerilen maçlar yeşil, önerilmeyen/model değerlendirmesi olan maçlar sarı görünümünü korur.
- İlk yarı, gol zamanı, korner, kart, ofsayt, şut ve oyuncu gibi ayrıntılı olay verisi isteyen sonuçlar veri yoksa uydurulmaz; `Sonuç verisi yok` gösterilir.
- Prisma şemasında ve migration dosyalarında değişiklik yoktur.

## Kurulum

Çalışan geliştirme sunucusunu `Ctrl+C` ile durdurun, sonra PowerShell'de:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3.3-compact-history-market-results*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.3 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:compact-history-v9
pnpm run test:market-catalog-v9
pnpm run test:prediction-workspace-v9
pnpm run test:all-matches-panels-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Kontrol adresleri:

- Kompakt geçmiş: `http://localhost:3000/evaluation`
- Önerilen/önerilmeyen tüm sonuçlar ve 27 pazar: `http://localhost:3000/prediction-results`

Not: Bu paket `.env` dosyasını içermez ve mevcut `.env` dosyanızı silmez.
