# Bet Project V9.5.3 — Kupon Boş Durum Düzeltmesi

## Sorunun nedeni

V9.5.2 güçlü ve zayıf kuponları aynı güncel-oran filtresinden geçiriyordu. API-Football Free plan 2026 fikstürlerini reddettiğinde ve oran çağrıları HTTP 429 limitine takıldığında mevcut seçimlerin oranları güçlü kupon için eski sayılıyor, ekrandaki bütün adaylar eleniyordu.

## Düzeltme

- Yüksek Güven, Dengeli ve Sürpriz kuponların güncel oran ve en az 3 bookmaker şartı korunur.
- Son 7 gün içinde hesaplanmış, başlamamış fakat oranı güçlü yayın eşiğine göre eski olan seçimler yalnız kırmızı `Zayıf / Önerilmez` filtresinde gösterilir.
- Her zayıf seçimde `Oran güncel değil`, `Bookmaker kapsamı yetersiz`, `Model olasılığı güçlü eşiğin altında`, `Beklenen değer düşük` ve `Piyasa avantajı düşük` uyarılarından geçerli olanlar gösterilir.
- Ekrana `Neden seçimler elendi?` paneli eklenmiştir.
- Başlamış/bitmiş maç, 1.10 altı oran, geçersiz model verisi ve 7 günden eski kayıtlar kullanılmaz.
- Sistem veri yoksa yine tahmin veya oran uydurmaz.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.5.3*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.5.3 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm run test:smart-coupons-v9
pnpm run test:coupon-performance-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm run value-bets
pnpm dev
```

`pnpm run value-bets` mevcut veritabanını kullanır ve dış API çağrısı yapmaz. Güçlü kuponları yeniden açmak için daha sonra 2026 sezonu ve yeterli oran kotası sunan API planı gerekir. `%20 ML / %80 Poisson` modeli değiştirilmemiştir.
