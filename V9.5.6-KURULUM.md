# V9.5.6 — Yaklaşan Maçlarda Gelişmiş Pazarları Açma

Bu sürüm, V9.5.5 ile alınan korner, kart, ofsayt ve şut verilerini yaklaşan maçların yayımlanmış tahmin kayıtlarına güvenli biçimde bağlar.

## Neden Veri Bekleniyordu?

- Yayımlanmış tahminler maçtan önce sabitlenir ve sayfa bu arşivi okur.
- Gelişmiş istatistikler tahmin arşivinden sonra alındığı için eski yaklaşan kayıtlar otomatik zenginleşmemişti.
- Sezon başında her takım için üç iç saha/deplasman örneği henüz oluşmamıştı.

V9.5.6 önce aynı saha rolündeki örnekleri, yeterli değilse takımın mevcut sezondaki son sekiz maçını kullanır. Her durumda en az üç gerçek istatistikli maç gerekir.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v9.5.6.zip" `
  -DestinationPath . `
  -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm run test:advanced-statistics-v9
pnpm exec tsc --noEmit
```

## Yaklaşan Tahminleri Zenginleştirme

Bu komut API isteği yapmaz. Yalnızca yaklaşan maçların yardımcı pazarlarını günceller; MS olasılıkları ve yayın kararları korunur.

```powershell
pnpm run markets:refresh-upcoming-v9

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Komut sonucunda `Korner aktif`, `Kart aktif`, `Ofsayt aktif` ve `Şut aktif` sayıları gösterilir. Bir pazar hâlâ bekliyorsa iki takımdan en az birinde üç gerçek istatistikli maç oluşmamıştır.
