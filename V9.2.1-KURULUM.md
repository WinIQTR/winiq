# Bet Project V9.2.1 — Günün En Güçlü Maçları

Bu kümülatif paket mevcut V9.1 cloud veya V9.2 cloud-compatible sürümünün üzerine kurulur.

## Değişiklik

- Kontrol Paneli yalnızca Türkiye saatine göre bugünün güçlü maçlarını gösterir.
- Önce bugünün en yüksek üretim puanlı en fazla 6 adayı seçilir.
- Seçilen maçlar başlangıç saatine göre eskiden yeniye sıralanır.
- Bugün uygun maç yoksa başka tarihlerden maç gösterilmez.
- Boş durumda `Bugün Güçlü Tahmin Bulunamadı` mesajı gösterilir.
- Model ağırlıkları, seçim eşikleri, Prisma ve veritabanı değiştirilmez.
- V9.2 `Tüm Maçlar` danışma tahmini paneli de pakete dahildir.

## Kurulum

Önce çalışan `pnpm dev` işlemini `Ctrl+C` ile durdurun.

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.1-daily-strongest-fixtures*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.1 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Başarılı yeni test çıktısı:

```text
V9.2.1 daily strongest predictions tests passed.
```
