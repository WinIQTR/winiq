# Bet Project V9.4.1

Bu paket V9.4.0 üzerine kurulur ve API satın almadan çalışabilir. Mevcut tahmin
snapshot ve sonuç arşivini okur; veri yenileme veya model ağırlığı değişikliği yapmaz.

## Eklenenler

- 27 bahis türü için beklenen ve gerçek başarı karşılaştırması
- Kalibrasyon farkı (gerçek başarı eksi beklenen başarı)
- Lig, seçim, MS 1/MS 0/MS 2 ve ev/deplasman ayrımları
- Veri kalitesi seviyesine göre performans
- 1–9 yetersiz, 10–29 gelişiyor, 30+ yeterli örneklem uyarısı
- En çok kaybettiren lig ve seçimler
- En başarılı olasılık aralıkları
- Model adil oranı için minimum 1.10 kontrolü
- Bookmaker oranı ile model adil oranını ayıran açıklama

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v9.4.1.zip" `
  -DestinationPath . `
  -Force

pnpm run test:calibrated-market-performance-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Kontrol adresi: http://localhost:3000/match-result-performance

## Güvenlik notu

Bu kurulum `pnpm run refresh`, `pnpm run archive` veya Prisma migration çalıştırmaz.
Yüzde sınıflandırması aynı kalır: %60+ güçlü, %50–59,9 orta, %40–49,9 inceleme,
%40 altı resmi öneri değildir. %40–59 kayıtları kalibrasyon arşivinde korunur.
