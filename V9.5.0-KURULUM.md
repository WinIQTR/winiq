# Bet Project V9.5.0 — Akıllı Kupon Merkezi

## Yeni özellikler

- Yönetici görünümü: `/coupons`
- Üye görünümü: `/member/coupons`
- Bugün ve önümüzdeki 7 gün filtreleri
- 2–5 yüksek güven, 5–10 dengeli ve 10–30 sürpriz kuponları
- Mümkün olan en az maçla hedef oranı oluşturma
- Aynı maçtan yalnızca bir seçim kullanma
- Gerçek bookmaker oranı, model olasılığı, piyasa farkı, EV ve geçmiş sonuç desteği
- Başlamış/bitmiş maç, eski oran, 1.10 altı oran ve yetersiz bookmaker kapsamını eleme
- Kalite eşikleri sağlanmıyorsa tahmin uydurmayan güvenli boş durum
- Her kupon için anlaşılır gerekçe ve risk açıklaması

## Üyelik görünümü

| Paket | Gösterilen kupon ve veriler |
|---|---|
| Temel | Günlük 2–5 kupon, maç/seçim/toplam oran |
| Analiz | Günlük ve haftalık 2–5/5–10 kupon, model olasılığı ve geçmiş başarı |
| Profesyonel | Tüm filtreler, sürpriz kupon, EV, piyasa farkı, değer puanı ve bookmaker kapsamı |

Üyelik fiyatları değiştirilmemiştir.

## Güvenli kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.5.0*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.5.0 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:smart-coupons-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Bu pakette Prisma migration yoktur. Kurulum sırasında `pnpm run refresh` veya tahmin arşivi otomatik çalıştırılmaz. API çağrısı yapılmaz. Modelin `%20 ML / %80 Poisson` kilidi değiştirilmemiştir.
