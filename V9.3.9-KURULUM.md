# Bet Project V9.3.9

Bu paket V9.3.8'in tüm dosyalarını ve 1X2 favori performansı düzeltmesini içerir.

## Yenilikler

- Maç sonucu performansı artık yalnızca yayımlanmış MS 1 pazar kayıtlarına bağlı değildir.
- Her maçta arşivlenmiş maç öncesi `MS 1 / MS 0 / MS 2` olasılıkları karşılaştırılır.
- En yüksek olasılığa sahip seçenek 1X2 model favorisi olarak seçilir.
- Favori en az `%30` ise listeye dahil edilir.
- Beraberlik favorileri `MS 0 · Beraberlik`, deplasman favorileri `MS 2 · Deplasman` olarak gösterilir.
- Başarı sonucu, başka bahis türlerinden bağımsız olarak kesin maç skorundan hesaplanır.
- Yüzde tablosu `%30–100` aralığını gösterir.
- Sayfa her açılışta mevcut tahmin arşivini yeniden okur.

Geçmiş sonuçlardan sonradan tahmin üretilmez. Maçtan önce saklanan 1X2 olasılıkları kullanılır.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3.9*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.9 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:match-result-performance-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```
