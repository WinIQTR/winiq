# Bet Project V9.2.2 — Tüm Maçlar Yeşil/Sarı Paneller

Bu kümülatif paket mevcut V9.1, V9.2 veya V9.2.1 cloud sürümünün üzerine kurulur.

## Değişiklikler

- `Tüm Maçlar` sekmesine yayımlanmış öneriler kesin olarak dahil edilir.
- Fikstür anlık görüntüsünde eksik kalan bir yayımlanmış tahmin listeden kaybolmaz.
- Resmî öneri kartları yeşil çerçeveyle gösterilir.
- Yeşil kartlarda aşağı açılan `Önerilen bahisleri göster` paneli bulunur.
- Panelde en fazla 5 seçim, model olasılığı, adil oran, güvenilirlik ve gerekçe gösterilir.
- Önerilmeyen, bekleyen veya hata alan diğer maçlar sarı çerçeveyle gösterilir.
- Sarı kartların danışma seçenekleri ve ret nedenleri açılır panelde korunur.
- Önerilen maçlar üstte; diğer maçlar ayraçtan sonra başlangıç saatine göre listelenir.
- V9.2 danışma paneli ve V9.2.1 günlük güçlü maç düzeni pakete dahildir.
- Model ağırlıkları, seçim eşikleri, Prisma ve veritabanı değiştirilmez.

## Kurulum

Önce çalışan `pnpm dev` işlemini `Ctrl+C` ile durdurun.

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.2-all-matches-green-amber-panels*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.2 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Başarılı yeni test çıktısı:

```text
V9.2.2 All Matches recommendation panel tests passed.
```
