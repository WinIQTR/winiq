# Bet Project V9.3.7 — Maç Sonucu 1X2 Performansı

Bu paket V9.3.6 ve önceki bütün kümülatif arayüz güncellemelerini içerir.

## Yeni sayfa

Adres: `http://localhost:3000/match-result-performance`

- Yalnızca maçtan önce yayımlanmış Maç Sonucu (1X2) tahminlerini gösterir.
- Toplam maç, sonuçlanan tahmin, kazanan, kaybeden, iade ve başarı oranını verir.
- MS 1, MS 0 ve MS 2 performanslarını ayrı hesaplar.
- Model olasılık aralıklarını tahmin, kazanan, kaybeden ve gerçek başarı oranıyla listeler.
- Her kayıtta tarih, lig, maç, yayımlanan seçim, model yüzdesi, adil oran,
  kesin skor ve Kazandı/Kaybetti sonucu bulunur.
- Takım/lig, seçim, gerçek sonuç ve minimum model yüzdesi filtreleri içerir.
- Uzun listeler 50 kayıtlık bölümler halinde açılır.
- Geçmiş maçlara sonradan tahmin üretilmez.
- Sidebar'a `1X2 Performance` bağlantısı eklendi.
- Prisma şeması ve model ağırlıkları değiştirilmedi.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads","$env:USERPROFILE\Desktop" `
  -Filter "bet-project-v9.3.7*.zip" `
  -File -Recurse -ErrorAction SilentlyContinue |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.7 ZIP dosyası bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:match-result-performance-v9
pnpm run test:match-result-labels-v9
pnpm run test:smart-evaluation-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Paket `.env` içermez ve Prisma migration gerektirmez.
