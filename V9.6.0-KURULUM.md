# Bet Project V9.6.0 — Pro Futbol Veri Merkezi

Bu sürüm Fikstürler, Takımlar, Oyuncular ve Top Scorers sayfalarını tek tasarım diliyle yeniler. API-Football Pro yanıtlarında bulunan stat, hakem, devre skoru, takım tesisi ve ayrıntılı oyuncu sezon alanları artık kaydedilir ve gösterilir.

## 1. Kurulum

PowerShell'i proje klasöründe açın ve sırasıyla çalıştırın:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  -Path "$env:USERPROFILE\Downloads\bet-project-v9.6.0.zip" `
  -DestinationPath "C:\Users\FMGammon\Desktop\bet-project" `
  -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm run test:football-data-v9
pnpm exec tsc --noEmit
```

## 2. Pro verilerini öncelik sırasıyla çekme

```powershell
$env:CONFIRM_FOOTBALL_DATA_REFRESH = "YES"
$env:FOOTBALL_DATA_MAX_REQUESTS = "1200"
$env:FOOTBALL_DATA_RECENT_MATCHES = "20"
$env:API_FOOTBALL_MIN_INTERVAL_MS = "500"
$env:API_FOOTBALL_PLAYER_MAX_PAGE = "100"

pnpm run data:refresh-pro-v9
pnpm run data:coverage-v9
```

İsteğe bağlı olarak biten son maçların oyuncu bazlı performanslarını da çekmek için yenilemeden önce:

```powershell
$env:FOOTBALL_DATA_PLAYER_MATCHES = "YES"
```

Bu seçenek daha fazla API isteği tüketir. Sistem bütçeyi şu sırayla kullanır:

1. Takımlar ve fikstürler
2. Oyuncu kadroları ve sezon istatistikleri
3. Sakatlık/eksik oyuncular ve maç takım istatistikleri
4. İsteğe bağlı oyuncu maç performansları

API'nin belirli bir lig veya maç için sunmadığı alanlar tahmin edilmez; sayfada `–` olarak görünür.

## 3. Başlatma

```powershell
pnpm build
pnpm dev
```

Kontrol adresleri:

- `http://localhost:3000/fixtures`
- `http://localhost:3000/teams`
- `http://localhost:3000/players`
- `http://localhost:3000/top-scorers`
