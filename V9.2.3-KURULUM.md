# Bet Project V9.2.3 — Kompakt Tüm Maçlar Listesi

Bu kümülatif paket mevcut V9.1, V9.2, V9.2.1 veya V9.2.2 cloud sürümünün üzerine kurulur.

## Değişiklikler

- `Tüm Maçlar` sekmesinde gün filtresi kaldırıldı; sezon arşivindeki bütün maçlar gösterilir.
- Lig seçildiğinde seçilen ligin bütün sezon maçları gösterilir.
- Yayımlanmış öneriler yeşil çerçeveyle listenin en üstünde gösterilir.
- Önerilmeyen, bekleyen ve hata alan diğer maçlar sarı çerçeveyle gösterilir.
- Her grubun kendi içinde maçlar tarih ve başlangıç saatine göre sıralanır.
- Kapalı maç kartları tek, kompakt yatay satır olarak gösterilir.
- Tarih, saat, lig, takımlar, öneri durumu ve ana seçim aynı satırda görünür.
- Uzun güven, xG, kalite, açıklama ve kontrol bilgileri açılır panelin içine taşındı.
- Yeşil ve sarı bahis panelleri satırın altında açılır.
- V9.2 danışma paneli, V9.2.1 günlük güçlü maç düzeni ve V9.2.2 yeşil/sarı sistem pakete dahildir.
- Model ağırlıkları, seçim eşikleri, Prisma ve veritabanı değiştirilmez.

## Kurulum

Önce çalışan `pnpm dev` işlemini `Ctrl+C` ile durdurun.

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.3-compact-all-matches-list*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.3 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Başarılı yeni test çıktısı:

```text
V9.2.3 compact All Matches row tests passed.
```
