# Bet Project V9.2.6 — Başlamamış ve Biten Maç Ayrımı

Bu paket V9.2.1–V9.2.5 arayüz geliştirmelerini ve V9.2.6 maç durumu ayrımını birlikte içerir.

## V9.2.6 değişiklikleri

- **Tüm Maçlar** sekmesinde yalnızca başlama zamanı gelmemiş, skoru olmayan ve `SCHEDULED`/`NOT_STARTED` durumundaki maçlar gösterilir.
- Tarihi geçtiği hâlde hâlâ başlamamış görünen eski kayıtlar Tüm Maçlar listesinden çıkarılır.
- `LIVE`, `POSTPONED`, `CANCELLED` ve `FINISHED` durumundaki maçlar Tüm Maçlar listesine alınmaz.
- **Biten** sekmesinde `FINISHED` durumundaki veya sonucu kaydedilmiş maçlar gösterilir.
- Tüm Maçlar ve Biten sekmelerinin sayaçları gerçek filtrelenmiş toplamları gösterir.
- Tüm Maçlar kronolojik, Biten Maçlar ise yayınlanmış öneriler üstte olacak şekilde en yeni sonuçtan eskiye sıralanır.
- Takım arama ve lig filtresi her iki sekmede de korunur.
- Önerilen maçlar yeşil, yalnızca model değerlendirmesi olan maçlar sarı çerçeveli gösterilmeye devam eder.

Model ağırlıkları, Prisma şeması ve veritabanı yapısı değiştirilmemiştir.

## Kurulum

PowerShell'de çalışan geliştirme sunucusunu `Ctrl+C` ile durdurun ve aşağıdaki komutları çalıştırın:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.6-upcoming-finished-separation*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.6 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

## Görsel kontrol

`http://localhost:3000/predictions` adresinde:

1. **Tüm Maçlar** sekmesinde skor yazan veya geçmiş tarihli maç bulunmadığını doğrulayın.
2. **Biten** sekmesinde sonuçlanmış maçların skorlarıyla göründüğünü doğrulayın.
3. Lig ve takım arama filtrelerini iki sekmede de deneyin.
4. Yeşil kartların yayınlanmış önerileri, sarı kartların önerilmeyen model değerlendirmelerini gösterdiğini kontrol edin.
