# Bet Project V6.8 — Arayüz ve Veri Deneyimi

Bu paket mevcut proje klasörünün üzerine açılacak kümülatif kaynak güncellemesidir.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v6.8-dashboard-fixtures-players-experience.zip" `
  -DestinationPath . `
  -Force

pnpm exec prisma generate
pnpm run test:experience-v6
pnpm run test:language-consistency-v6
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

## Tüm organizasyonların oyuncu verisini yenileme

Bu işlem ücretli API kotası kullanır ve bu nedenle açık onay olmadan başlamaz.

```powershell
$env:CONFIRM_ALL_PLAYER_IMPORT = "YES"
$env:PLAYER_PERFORMANCE_MATCH_LIMIT = "10"
pnpm run players:refresh-all-v6
Remove-Item Env:CONFIRM_ALL_PLAYER_IMPORT
Remove-Item Env:PLAYER_PERFORMANCE_MATCH_LIMIT
```

İlk çalıştırmada organizasyon sayısına ve API hız sınırına göre süre uzayabilir. Komut model ağırlığını değiştirmez.
