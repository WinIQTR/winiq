BET PROJECT V5.4 - ADVISORY PREDICTIONS FOR FILTERED MATCHES

This is a cumulative package applied on top of the verified V5.2 project.
It includes V5.3 result reconciliation and V5.4 advisory predictions, so the
separate V5.3 ZIP does not need to be installed first.

ALL MATCHES DISPLAY LEVELS

GREEN
Published recommendation. Every Selection Policy V2 check passed.

AMBER
The model produced a prediction, but at least one publication check failed.
The card shows the strongest available estimate, probability, confidence,
data quality and expected goals. It is explicitly marked NOT A RECOMMENDATION.

GRAY
The match has not been evaluated yet, usually because it has not entered the
60-day production calculation window.

RED
The model evaluation could not be completed.

The Why was it not recommended? control expands on click and works on both
desktop and mobile. Failed checks are listed before passed checks.

V5.3 additionally checks missing final scores, pending settlements, immutable
archive score mismatches and overdue match statuses on the Operations page.

No model weight, production lock, external notification setting or API secret
is changed. The Champion remains 20% ML / 80% Poisson.
