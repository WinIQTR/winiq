# Bet Project V9.5.2 — Kupon Performansı

## Eklenenler

- Yönetici sayfası: `/coupon-performance`
- Üye sayfası: `/member/coupon-performance`
- Yayınlanan kupon ve kupon seçimlerini değiştirilemez biçimde saklayan veritabanı arşivi
- Otomatik `PENDING / WON / LOST / VOID` sonuçlandırma
- Kupon türüne göre başarı oranı
- Toplam, sonuçlanan, kazanan, kaybeden, bekleyen ve iade sayıları
- Sabit birim kâr ve ROI
- Kupon türü, günlük/haftalık kapsam ve sonuç filtreleri
- Açılır maç listesinde yayın oranı, model olasılığı, gerçek skor ve seçim sonucu
- Zayıf kuponlarda kırmızı `Zayıf / Önerilmez` ayrımı

Başarı yüzdesi yalnız `WON + LOST` kuponlardan hesaplanır. `PENDING` ve `VOID` kayıtlar başarı yüzdesine katılmaz. Geçmişte kalıcı olarak yayınlanmamış kuponlar sonradan oluşturulmaz; güvenilir takip V9.5.2 ile başlar.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.5.2*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.5.2 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy

pnpm run test:smart-coupons-v9
pnpm run test:coupon-performance-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build

# Mevcut veritabanı ve oranlarla ilk kupon arşivini oluşturur; dış API çağırmaz.
pnpm run value-bets

pnpm dev
```

Kontrol adresleri:

- Yönetici: `http://localhost:3000/coupon-performance`
- Üye: `http://localhost:3000/member/coupon-performance`

Bu sürüm `%20 ML / %80 Poisson` model ağırlıklarını değiştirmez. `pnpm run refresh` kurulum sırasında çalıştırılmaz ve API kotası kullanılmaz.
