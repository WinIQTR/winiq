Bu paket V2.4 uzerine kurulur.

DUZELTMELER
- package.json icine test:learning-v2 komutu kesin olarak eklenir.
- Eski V2.2 aciklama testindeki bestOdds: null tip hatasi duzeltilir.

KURULUM
1. Calisan pnpm run refresh islemi varsa tamamlanmasini bekleyin.
2. Calisan pnpm dev islemi varsa Ctrl+C ile durdurun.
3. ZIP icindeki package.json ve scripts klasorunu proje ana klasorune kopyalayip uzerine yazin.
4. Su komutlari AYRI AYRI calistirin. Her komut bittikten sonra sonrakini yazin:

pnpm run test:learning-v2
pnpm run test:accuracy-v2
pnpm run test:portfolio-v2
pnpm run test:explanation-v2
pnpm exec tsc --noEmit

5. Hepsi basariliysa:

pnpm run refresh
pnpm dev

NOT
- PowerShell satirinda >> gorunurse yeni komut yazmayin. Ctrl+C ile iptal edip komutlari tek tek girin.
