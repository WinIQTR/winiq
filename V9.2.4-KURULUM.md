# Bet Project V9.2.4 — Referans Tasarımlı Üç Sekme

Bu kümülatif paket mevcut V9.1–V9.2.3 cloud sürümlerinin üzerine kurulur.

## Değişiklikler

- Referans görseldeki gibi üç büyük sekme eklendi: `Önerilen Tahminler`, `Tüm Maçlar`, `Biten Maçlar`.
- Aktif sekme mavi çerçeveli, koyu mavi zeminli, kalın yazılı ve sayı rozetlidir.
- Pasif sekmeler çerçevesiz, büyük beyaz metin olarak gösterilir.
- Sekmeler geniş ekranda yatay, dar ekranda alt alta responsive çalışır.
- `Biten Maçlar` gerçek bir veri görünümüdür; skor kaydı, `FINISHED` durumu veya kapanmış tahmin sonucu bulunan maçları gösterir.
- Biten maçlarda yayımlanmış öneriler yeşil olarak üstte, diğer maçlar sarı olarak altta gösterilir.
- Önceki tek satırlı maç listesi ve aşağı açılan yeşil/sarı bahis panelleri korunur.
- V9.2–V9.2.3 özelliklerinin tamamı pakete dahildir.
- Model ağırlıkları, seçim eşikleri, Prisma ve veritabanı değiştirilmez.

## Kurulum

Önce çalışan `pnpm dev` işlemini `Ctrl+C` ile durdurun.

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.4-reference-three-tabs*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.4 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Başarılı yeni test çıktısı:

```text
V9.2.4 reference-style three-tab tests passed.
```
