# V9.5.7 — Kupon Tekilleştirme ve Tarihsel Doğrulama Tasarımı

Bu sürüm iki düzenleme içerir:

- Aynı maç, pazar ve seçimlerden oluşan günlük/haftalık kuponlar artık iki kez yayınlanmaz.
- Eski çift kayıtlar silinmeden Kupon Performansı ekranında tek kupon olarak sayılır; günlük kayıt önceliklidir.
- Haftalık kupon üretimi önce bugünden sonraki maçları kullanır. Böylece günlük kuponun kopyası yerine farklı bir haftalık kupon hazırlanır.
- `/smart-picks` ekranı yöneticiye özel, kompakt **Tarihsel Model Doğrulaması** sayfasına dönüştürüldü.
- Tarihsel 2024/25 test sonuçları ile güncel 2026/27 performansı açıkça ayrıldı.
- Kalibrasyon farkı, güven seviyeleri, lig/pazar tabloları ve denetim kayıtları daha okunaklı gösterilir.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v9.5.7.zip" `
  -DestinationPath . `
  -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm run test:smart-coupons-v9
pnpm run test:coupon-performance-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Yeni veritabanı geçişi yoktur. Geçmiş çift kayıtlar fiziksel olarak silinmez; denetim güvenliği için korunur, arayüz ve başarı hesaplarında tekilleştirilir.
