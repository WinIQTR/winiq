# V9.5.5 — Kota Koruması ve Pazar Bazlı Kapsam

Bu sürüm V9.5.4 gelişmiş maç istatistikleri aktarımının güvenli devamıdır.

## Yenilikler

- API-Football'ın istatistik vermediği maçlar `API_FOOTBALL_NO_DATA` olarak işaretlenir.
- Kapsam dışı maçlar sonraki çalıştırmalarda tekrar çağrılmaz.
- Kısmi istatistikler korunur ve yeniden API kotası tüketmez.
- Kapsam raporu korner, ofsayt, kart, şut ve isabetli şutu maç bazında ayrı ayrı gösterir.
- Ana `%20 ML / %80 Poisson` ağırlıkları değişmez.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v9.5.5.zip" `
  -DestinationPath . `
  -Force

pnpm exec prisma generate
pnpm exec prisma migrate deploy
pnpm run test:advanced-statistics-v9
pnpm exec tsc --noEmit
```

## Daha önce veri vermeyen maçları bir kez işaretleme

Bu işlem daha önce boş dönen maçları son kez kontrol eder. Boş dönenler kalıcı kapsam dışı işaretlenir ve sonraki aktarımlarda tekrar çağrılmaz.

```powershell
$env:CONFIRM_MATCH_STATS_IMPORT = "YES"
$env:MATCH_STATS_FROM = "2026-07-01"
$env:MATCH_STATS_TO = (Get-Date).ToString("yyyy-MM-dd")
$env:MATCH_STATS_MATCH_LIMIT = "250"
$env:API_FOOTBALL_MIN_INTERVAL_MS = "1200"

pnpm run statistics:import-v9
pnpm run statistics:coverage-v9
```

İkinci kez çalıştırıldığında `Aday` ve `API isteği` değerlerinin sıfıra yaklaşması beklenir. Yeni tamamlanmış maçlar geldikçe yalnızca onlar işlenir.
