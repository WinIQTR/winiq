# Bet Project V9.3.2 — Tahmin Merkezi ve Sonuç Arşivi

Bu kümülatif paket V9.2.1–V9.3.1 çalışmalarını ve V9.3.2 sayfa ayrımını içerir.

## V9.3.2 değişiklikleri

- Önerilen maçlarda tam genişlikli 27 pazar paneli ilk sırada gösterilir.
- Eski ayrıntılı model analizi ikinci, isteğe bağlı bir açılır bölüm olarak korunur.
- Tahminler sayfasındaki Biten sekmesi kaldırıldı.
- Sonuçlanan maçlar yeni `/prediction-results` sayfasına taşındı.
- Sol menüye **Prediction Results** bağlantısı eklendi.
- Tahminler sayfasının veritabanı sorgusu yalnız gelecekteki `SCHEDULED`, skoru olmayan maçları yükler.
- Tüm Maçlar görünümünde varsayılan dönem önümüzdeki 1 haftadır.
- Kullanıcı 1, 2 veya 3 haftalık maç aralığını seçebilir.
- Lig ve takım arama filtreleri seçilen hafta aralığıyla birlikte çalışır.
- Tahmin Sonuçları sayfası yalnız `FINISHED` veya skoru kaydedilmiş maçları listeler.
- Bahis Türüne Göre Performans bölümü iki sütunlu kompakt kartlara dönüştürüldü.
- Her performans kartında bahis türü, sonuçlanmış örnek sayısı, doğruluk yüzdesi ve kısa başarı çubuğu bulunur.

Model ağırlıkları (%20 ML / %80 Poisson), Seçim Politikası V2, Prisma şeması ve veritabanı değiştirilmemiştir.

## Kurulum

Çalışan `pnpm dev` ekranını `Ctrl+C` ile durdurun ve PowerShell'de çalıştırın:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3.2-predictions-results-week-window*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.2 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:prediction-workspace-v9
pnpm run test:market-catalog-v9
pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

## Kontrol adresleri

- Tahmin Sonuçları: `http://localhost:3000/prediction-results`
- Bahis türü performansı: `http://localhost:3000/evaluation`
