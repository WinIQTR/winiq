# Bet Project V9.3.8

Bu paket V9.3.7'nin tüm dosyalarını ve 1X2 performans arşivi güncellemesini içerir.

## Yenilikler

- `/match-result-performance` sayfası 15 Ağustos 2026'dan sayfanın açıldığı ana kadar olan kayıtları gösterir.
- Yalnızca maçtan önce arşivlenmiş `MATCH_RESULT`, `1X2` ve `FULL_TIME_RESULT` önerileri kullanılır.
- Model olasılığı için alt sınır yoktur; `%0–100` arasındaki tüm tahminler listelenir.
- Yüzde performansı 10'luk dilimlerle gösterilir; kaydı olmayan dilimler de tabloda kalır.
- Kazandı, kaybetti ve iade sayıları; kesin skor, seçim, model yüzdesi ve adil oran birlikte gösterilir.
- Arama, MS 1/MS 0/MS 2, gerçek sonuç ve olasılık aralığı filtreleri bulunur.
- Sayfa önbelleğe alınmaz; her açılışta güncel arşiv verisi yeniden okunur.

Geçmiş maçlar sonradan tahmine dönüştürülmez. Yalnızca maç başlamadan önce kaydedilmiş öneriler değerlendirilir.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3.8*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.8 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:match-result-performance-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Bu sürüm Prisma migration içermez ve model ağırlıklarını değiştirmez.
