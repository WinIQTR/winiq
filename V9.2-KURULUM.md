# Bet Project V9.2 — Cloud Uyumlu Tüm Maçlar Danışma Paneli

Bu paket, cloud ile geliştirilen **V9.1 Automatic Prediction Archive** sürümünün üzerine kurulmak üzere hazırlanmıştır.

## Önemli karar

`bet-project-v6.8.1-all-matches-advisory-details.zip` dosyasını V9.1 projesinin üzerine doğrudan kurmayın. V6.8.1 daha eski kaynak dosyaları içerdiği için cloud döneminde eklenen özellikleri geri alabilir.

V9.2 paketi yalnızca gerekli danışma paneli değişikliklerini içerir ve şu V9/V9.1 özelliklerini korur:

- Otomatik tahmin arşivi, maç öncesi yayın ve maç sonrası sonuçlandırma
- Tekrarlanan yayınları engelleyen değişmez yayın kimliği
- Takım son-form göstergeleri ve önerilen/diğer maç ayrımı
- Sakatlık ve oyuncu veri aktarımı
- Gol krallığı sayfası
- Yeni kart, korner, ilk yarı ve oyuncu golcü piyasaları
- Rate-limit, zaman yardımcıları ve uygulama hata sayfaları
- 2026 aktif sezonu
- 20% ML / 80% Poisson Champion ve otomatik model değişikliği kilidi

## Eklenen özellik

`Tahminler > Tüm Maçlar` görünümündeki filtrelenmiş maçlarda aşağı açılan danışma paneli bulunur.

- En fazla 5 model seçeneği
- Model olasılığı
- Modelden hesaplanan adil oran
- Kısa hesaplama açıklaması
- Maçın neden resmî öneri olarak yayımlanmadığını gösteren politika kontrolleri
- Türkçe ve İngilizce piyasa/seçim adları
- Veri yetersizse tahmin uydurmayan güvenli boş durum

Sarı/kehribar paneldeki seçenekler **resmî bahis önerisi değildir**.

## Windows kurulumu

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

Expand-Archive `
  "$env:USERPROFILE\Downloads\bet-project-v9.2-cloud-compatible-advisory-details.zip" `
  -DestinationPath . `
  -Force

pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Tarayıcıda `http://localhost:3000/predictions` adresine gidin, **Tüm Maçlar** sekmesini seçin ve sarı karttaki **Bahis seçeneklerini ve nedenleri göster** satırını açın.

Bu sürüm için Prisma migration gerekmez. `pnpm run archive` veya `pnpm run refresh` komutları kurulum sırasında otomatik çalıştırılmaz; üretim verisi ve model ayarları değiştirilmez.
