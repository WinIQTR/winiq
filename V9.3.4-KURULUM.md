# Bet Project V9.3.4 — Akıllı Tahmin Performansı

Bu paket V9.3.3 değişikliklerini de içeren kümülatif güncellemedir.

## Yenilikler

- Model Performance başlığı `Akıllı Tahmin Performansı` olarak yenilendi.
- Başarı halkası ve örneklem büyüklüğüne duyarlı Model Sağlığı eklendi.
- Arşivlenen tahmin, genel başarı, yüksek güven başarısı ve ortalama olasılık kartları sadeleştirildi.
- En başarılı bahis türü, kalibrasyon farkı ve yüksek güven etkisi tek satırlık içgörülere dönüştürüldü.
- Bahis türü performansında Kazandı/Kaybetti/İade dağılımı açıkça gösteriliyor.
- Güven seviyesi kartlarına karşılaştırmalı performans çubukları eklendi.
- Olasılık kalibrasyonu daha açıklayıcı Türkçe etiketlerle düzenlendi.
- Mobil ve tablet görünümü yenilendi.
- V9.3.3 kompakt geçmiş ve 27 pazar sonuç özellikleri korunuyor.
- Model ağırlıkları, Prisma şeması ve migration dosyaları değiştirilmedi.

## Kurulum

Çalışan sunucuyu `Ctrl+C` ile durdurun. ZIP dosyasını Downloads veya Desktop
klasörüne indirdikten sonra PowerShell'de:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$SearchFolders = @(
  "$env:USERPROFILE\Downloads",
  "$env:USERPROFILE\Desktop"
)

$PatchZip = Get-ChildItem `
  -Path $SearchFolders `
  -Filter "bet-project-v9.3.4*.zip" `
  -File `
  -Recurse `
  -ErrorAction SilentlyContinue |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.4 ZIP dosyası bulunamadı."
}

$PatchZip | Format-List FullName,Length,LastWriteTime

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:smart-evaluation-v9
pnpm run test:compact-history-v9
pnpm run test:market-catalog-v9
pnpm run test:prediction-workspace-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Kontrol adresi: `http://localhost:3000/evaluation`

Paket `.env` içermez; mevcut `.env` dosyanız korunur.
