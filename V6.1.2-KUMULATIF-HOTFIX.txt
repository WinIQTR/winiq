BET PROJECT V6.1.3 - KUMULATIF HOTFIX

Bu paket V6.1.1 ValueBetHistory duzeltmesini, /login sayfasi duzeltmesini
ve yonetici korumali ortak loading.tsx kaynakli 307 dongusu duzeltmesini
birlikte icerir. Yeni migration gerekmez.

1) Tarayici sekmesini kapatin.
2) Calisan pnpm dev terminalinde Ctrl+C basin.
3) ZIP dosyasini proje kokune acin.
4) Calistirin:

   pnpm exec prisma format
   pnpm exec prisma generate
   pnpm run test:value-history-hotfix-v6
   pnpm run test:membership-v6
   pnpm run test:login-loop-v6
   pnpm exec tsc --noEmit
   Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
   pnpm build
   pnpm dev

5) Microsoft Edge InPrivate penceresinde su adresi acin:
   http://localhost:3000/login

Giris sayfasi artik mevcut veya gecersiz bir oturum nedeniyle otomatik
yonlendirme yapmaz. Basarili giristen sonraki yonlendirmeyi login API sonucu
ve form gerceklestirir.
