# Bet Project V9.2.5 — Akıllı Tahmin Çalışma Alanı

Bu kümülatif paket mevcut V9.1–V9.2.4 cloud sürümlerinin üzerine kurulur.

## Neden değiştirildi?

Eski ekranda uzun ve tekrarlanan açıklamalar, büyük sekmeler, dokuz ayrı lig düğmesi ve tekrar eden sayaçlar maç listesini aşağı itiyordu. Yeni düzen, en sık kullanılan işlemleri tek kompakt kontrol alanında toplar.

## Değişiklikler

- Sayfa başlığı ve açıklamalar kısaltıldı.
- Tekrarlanan `2026 Fikstür ve Tahmin Merkezi` başlığı sade `Maçları İncele` başlığına dönüştürüldü.
- Üç görünüm kompakt segmented control olarak tasarlandı.
- `Önerilen`, `Tüm Maçlar` ve `Biten` sekmelerinin sayıları her zaman görünür.
- Takım adına göre anlık arama eklendi.
- Dokuz lig düğmesi kaldırılıp tek lig açılır menüsü eklendi.
- `Filtreleri temizle` düğmesi eklendi.
- Canlı veri durumu, görüntülenen maç ve öneri sayısı tek alanda birleştirildi.
- Tekrarlanan `maç yüklendi` ve liste üstü sayaç kutusu kaldırıldı.
- Önerilen görünümündeki tarih ve hızlı filtreler korunurken gereksiz olasılık sürgüsü kaldırıldı.
- Türkçe ve İngilizce yeni başlık/açıklama karşılıkları eklendi.
- Sayfa ve kontrol alanı masaüstü, tablet ve mobil için responsive yapıldı.
- Yeşil/sarı tek satırlı maçlar ve açılır bahis panelleri korundu.
- V9.2–V9.2.4 özelliklerinin tamamı pakete dahildir.
- Model ağırlıkları, seçim eşikleri, Prisma ve veritabanı değiştirilmez.

## Kurulum

Önce çalışan `pnpm dev` işlemini `Ctrl+C` ile durdurun.

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.2.5-smart-prediction-workspace*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.2.5 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Başarılı yeni test çıktısı:

```text
V9.2.5 smart prediction workspace tests passed.
```
