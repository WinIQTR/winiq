- 27 pazar masaüstünde üç sütundan iki sütuna geçirildi.
- Pazar isimleri ve öne çıkan seçimler artık üç noktayla kesilmez.
- Her kartta `PAZAR`, `ÖNE ÇIKAN SEÇİM`, `PUAN` ve seviye ayrı gösterilir.

- Tablet görünümünde tek sütun; telefonda üç satırlı kompakt kart kullanılır.
- 27 pazar hesapları, puanlar ve model değerleri değiştirilmedi.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads","$env:USERPROFILE\Desktop" `
  -Filter "bet-project-v9.3.6*.zip" `
  -File -Recurse -ErrorAction SilentlyContinue |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.6 ZIP dosyası bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:market-readability-v9
pnpm run test:market-catalog-v9
pnpm run test:match-result-labels-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Paket `.env` içermez ve Prisma migration gerektirmez.
