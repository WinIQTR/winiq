# Bet Project V9.3.1 — Tam Genişlikte Bahis Panelleri

Bu paket V9.2.1–V9.3 özelliklerini ve V9.3.1 yerleşim düzenlemesini birlikte içerir.

## V9.3.1 değişiklikleri

- Sağ sütunun içinde açılarak kartı gereksiz uzatan eski bahis pencereleri kaldırıldı.
- Maçın lig, tarih, takım, skor/durum ve ana tahmini yatay satırda kalır.
- **27 bahis pazarını ve puanları göster** paneli maç satırının hemen altında, kartın tam genişliğinde açılır.
- Geniş ekranlarda üç, orta ekranlarda iki, mobil ekranlarda tek sütun kullanılır.
- Önerilen maçların kalite onayı aynı alt panelde gösterilir.
- Önerilmeyen maçların güven, veri kalitesi ve reddedilme nedenleri aynı alt panelde gösterilir.
- Aynı 27 pazar paneli şu alanlarda kullanılır:
  - Tahminler / Önerilen
  - Tahminler / Tüm Maçlar
  - Tahminler / Biten
  - Yönetim Dashboard tahmin listesi
- Açık panelde 27 ana pazar; yeşil, sarı, kırmızı ve veri bekleniyor ayrımıyla listelenir.
- Her pazar satırı ayrıca açılarak tüm hesaplanan seçenekler görülebilir.

Model ağırlıkları (%20 ML / %80 Poisson), Seçim Politikası V2, Prisma şeması ve veritabanı değiştirilmemiştir.

## Kurulum

Çalışan `pnpm dev` ekranını `Ctrl+C` ile durdurun ve PowerShell'de aşağıdaki bloğu çalıştırın:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3.1-full-width-market-panels*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.1 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:market-catalog-v9
pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

## Kontrol

`http://localhost:3000/predictions` adresinde Önerilen, Tüm Maçlar ve Biten sekmelerini ayrı ayrı kontrol edin. Panel açıldığında maç satırının sağ tarafında dar bir pencere oluşmamalı; içerik satırın altında bütün kart genişliğini kullanmalıdır.
