# Bet Project V9.3.5 — Maç Sonucu 1X2 Etiketleri

Bu paket V9.3.4 ve önceki kümülatif arayüz güncellemelerini içerir.

## Düzeltme

- Ev Sahibi, Beraberlik ve Deplasman yüzdelerinin `90 dakika Maç Sonucu (1X2)`
  olasılıkları olduğu açıkça belirtildi.
- Kart başlığı `MAÇ SONUCU OLASILIKLARI · 1X2` olarak eklendi.
- Seçenekler `MS 1 · Ev Sahibi`, `MS 0 · Beraberlik`, `MS 2 · Deplasman`
  biçiminde gösteriliyor.
- Aynı açıklamalar detaylı model analizi paneline de eklendi.
- Ortak tahmin kartı kullanıldığı için değişiklik bütün tahmin alanlarına yansır.
- Tahmin değerleri, model ağırlıkları ve Prisma şeması değiştirilmedi.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

$SearchFolders = @(
  "$env:USERPROFILE\Downloads",
  "$env:USERPROFILE\Desktop"
)

$PatchZip = Get-ChildItem `
  -Path $SearchFolders `
  -Filter "bet-project-v9.3.5*.zip" `
  -File `
  -Recurse `
  -ErrorAction SilentlyContinue |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3.5 ZIP dosyası bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:match-result-labels-v9
pnpm run test:smart-evaluation-v9
pnpm run test:compact-history-v9
pnpm run test:market-catalog-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Paket `.env` içermez ve Prisma migration gerektirmez.
