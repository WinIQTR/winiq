# Bet Project V9.5.1 — Zayıf Kupon Görünümü

V9.5.0 üzerine aşağıdaki özellikler eklenmiştir:

- Günlük ve haftalık kuponlarda `2–10 · Zayıf / Önerilmez` filtresi
- Kırmızı kupon çerçevesi ve `RESMÎ ÖNERİ DEĞİL` etiketi
- Her zayıf kupon için düşük güven/değer açıklaması
- Temel üyede günlük, Analiz ve Profesyonel üyede günlük/haftalık zayıf kupon görünümü
- Başlamış maç, eski oran, 1.10 altı oran ve üçten az bookmaker kaynağı için mevcut güvenlik engelleri

Zayıf kuponlar resmî öneri veya kazanç garantisi değildir; karşılaştırma ve model takibi amacıyla gösterilir.

## Kurulum

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.5.1*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.5.1 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive -Path $PatchZip.FullName -DestinationPath . -Force

pnpm run test:smart-coupons-v9
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

Bu pakette Prisma migration yoktur. API çağrısı yapılmaz ve `%20 ML / %80 Poisson` model kilidi değiştirilmez.
