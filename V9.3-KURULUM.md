# Bet Project V9.3 — 27 Pazarlık Puanlı Maç Analizi

Bu paket V9.2.1–V9.2.6 güncellemelerini ve yeni V9.3 bahis pazarı panelini birlikte içerir.

## Yeni özellikler

- Tüm Maçlar ve Biten sekmelerindeki her maçta **27 ana bahis pazarı** aynı sırayla listelenir.
- Her pazarın en güçlü seçeneği kapalı satırda görülür; satır açıldığında diğer seçenekler gösterilir.
- Hesaplanan her seçenekte model olasılığı, adil oran ve 0–100 öneri puanı bulunur.
- Puan sınıfları:
  - 70–100: yeşil, güçlü
  - 55–69,9: sarı, orta
  - 0–54,9: kırmızı, önerilmez
- Hesaplanamayan pazarlar kırmızı tahmin gibi gösterilmez; gri **Veri bekleniyor** durumunda tutulur.
- Yaklaşık ilk yarı ve zaman modeli hesapları açıkça **Yaklaşık model hesabı** etiketi taşır.
- Kart, korner ve oyuncu pazarları yalnızca ilgili gerçek istatistik mevcutsa puanlanır.
- Ofsayt, şut, gol zamanı ve ayrıntılı oyuncu pazarlarında gerekli veri yoksa tahmin üretilmez.
- Önerilen maçların yeşil, önerilmeyen maçların sarı dış çerçevesi korunur.
- Tüm Maçlar yalnız başlamamış gelecek maçları; Biten yalnız sonuçlanmış maçları gösterir.

## Puan formülü

Pazar puanı; model olasılığının %82'si ile maç güven/veri kalitesi puanının %18'inden oluşur. Yaklaşık hesaplanan pazarlara 5 puan temkin indirimi uygulanır. Bu puan bahis şirketi oranı veya kazanç garantisi değildir.

Model ağırlıkları (%20 ML / %80 Poisson), Seçim Politikası V2, Prisma şeması ve veritabanı değiştirilmemiştir.

## Kurulum

Çalışan `pnpm dev` ekranını `Ctrl+C` ile durdurup PowerShell'de aşağıdaki bloğu çalıştırın:

```powershell
cd C:\Users\FMGammon\Desktop\bet-project

Get-Process node -ErrorAction SilentlyContinue |
  Stop-Process -Force

pnpm run backup:production
pnpm run verify:backup

$PatchZip = Get-ChildItem `
  "$env:USERPROFILE\Downloads" `
  -Filter "bet-project-v9.3-scored-27-market-catalog*.zip" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1

if (-not $PatchZip) {
  throw "V9.3 ZIP dosyası Downloads klasöründe bulunamadı."
}

Expand-Archive `
  -Path $PatchZip.FullName `
  -DestinationPath . `
  -Force

pnpm run test:market-catalog-v9
pnpm run test:all-matches-panels-v9
pnpm run test:daily-strongest-v9
pnpm run test:advisory-details-v9
pnpm run test:archive
pnpm exec tsc --noEmit

Remove-Item .next -Recurse -Force -ErrorAction SilentlyContinue
pnpm build
pnpm dev
```

## Kontrol

`http://localhost:3000/predictions` adresinde Tüm Maçlar sekmesine geçin. Yeşil veya sarı maç kartındaki **Tüm bahis pazarlarını göster** alanını açın. Panelde 27 başlık, hesaplanmış pazar sayısı, renk özeti ve her seçeneğin puanı görünmelidir.
